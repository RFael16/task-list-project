# 📝 Task List Project

Uma aplicação simples e intuitiva de lista de tarefas (To-Do List) desenvolvida para organizar o dia a dia e praticar conceitos de desenvolvimento web.

## 🛠️ Tecnologias Utilizadas
* HTML5 (Estruturação)
* CSS3 (Estilização e Design Responsivo)
* JavaScript (Lógica de adicionar, concluir e remover tarefas)

## 📦 Como rodar o projeto localmente
1. Clique no botão verde **Code** (no topo desta página) e selecione **Download ZIP**.
2. Extraia a pasta compactada no seu computador.
3. Abra o arquivo **`index.html`** dando dois cliques para ver o site funcionando no navegador.
